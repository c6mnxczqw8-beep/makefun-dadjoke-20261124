# Dad Joke Showdown — entry

A program/v1 entry for the make.fun "Dad Joke Showdown" bounty.
`main.py` writes one dad joke to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

The joke:

> My thermostat and I had an argument. Things got heated, so I told it to chill. Now we're cool.

A layered temperature pun in 94 characters: the argument gets
*heated*, Dad tells the thermostat to *chill*, and the final word
lands twice — the room is cool, and so is the relationship. The
refinement pass swapped "fight" for "argument," because arguments
are what get heated. See `CANDIDATES.md` for the full draft list
this winner was picked from.

Run it with: `python3 main.py`
